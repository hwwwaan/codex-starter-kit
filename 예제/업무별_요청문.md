# 업무별 요청문

아래 문장을 그대로 복사한 뒤 대괄호 부분만 바꿔도 됩니다.

## 자료 전체 검토

> 01_자료의 관련 파일을 먼저 목록화하고 결론에 영향을 주는 내용은 전체 확인해 줘. [알고 싶은 것]을 사실, 해석, 가설로 구분하고 기존 자료끼리 충돌하는 지점도 찾아 줘.

## 최신 정책·제도 조사

> [주제]의 현재 정책과 제도를 조사해 줘. 공식 원문을 우선 확인하고 확인 날짜와 출처를 붙여 줘. 내 결론을 지지하는 자료뿐 아니라 반대 근거와 예외도 검토해 줘.

## 회의 정리

> [회의 파일명]을 읽고 결정사항, 담당자별 할 일, 기한, 미결 쟁점을 구분해 줘. 원문에 없는 담당자나 결정을 만들지 말고 근거를 추적할 수 있게 해 줘.

## 보고서 작성

> 01_자료를 바탕으로 [독자]가 [목적]에 사용할 [분량] 보고서를 만들어 줘. 먼저 주장과 근거가 맞는지 확인하고, 최종 파일은 03_완성본에 저장한 뒤 전체 내용을 검수해 줘.

## 발표자료 작성

> [주제]를 [청중]에게 [발표시간] 동안 설명할 발표자료를 만들어 줘. 한 장에 메시지 하나만 두고, 장표 제목만 읽어도 논리가 이어지게 해 줘. 수치와 도표의 출처를 표시하고 렌더링까지 검수해 줘.

## 엑셀·CSV 분석

> [파일명]의 시트, 행, 열, 결측, 중복, 단위와 기간을 먼저 점검해 줘. 그다음 [분석 질문]을 계산하고 핵심 합계와 비율을 재검산해 줘. 분석 한계와 재현 가능한 계산 근거도 남겨 줘.

## 대안 선택

> [결정할 문제]에서 가장 좋은 방안을 하나 권고해 줘. 목표, 반드시 지킬 제약, 시간과 비용, 실패 시 손실, 기회비용을 비교하고 권고가 바뀌는 조건도 알려 줘.

## 팀 상황 기억

> 우리 팀의 현재 목표, 역할, 마감, 확정 결정과 산출물 기준을 알려줄게. 기존 팀 업무정본을 먼저 읽고, 없는 내용만 한 번에 하나씩 짧게 물어본 뒤 확인된 정보만 기록해 줘.

## 제출 전 감사

> 03_완성본의 [파일명]을 제출 전 독립 감사해 줘. 원요청, 근거, 수치, 반증, 개인정보, 내부 흔적, 파일 열림과 페이지 배치를 모두 확인하고 PASS 또는 BLOCK으로 판정해 줘. BLOCK이면 고칠 수 있는 결함은 직접 수정한 뒤 다시 검사해 줘.
