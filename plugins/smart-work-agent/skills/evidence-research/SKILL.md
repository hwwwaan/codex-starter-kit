# 근거 중심 조사

주장을 먼저 정하고 근거를 끼워 맞추지 않는다. 조사 범위와 확인 강도를 정한 뒤 원문을 수집하고 결론을 도출한다.

## 조사 절차

1. 조사 질문, 기간, 지역, 대상, 필요한 정확도를 확정한다.
2. 작업공간의 기존 자료와 정본을 먼저 확인한다.
3. 최신성이 변할 수 있으면 인터넷을 검색한다. 법령·정부·기관·연구자·원데이터 등 1차 또는 공식 출처를 우선한다.
4. 검색 결과 문구가 아니라 실제 원문을 열어 전후 맥락을 확인한다.
5. [근거 원장](references/evidence-ledger.md)에 핵심 주장, 근거, 반증, 확인상태를 연결한다.
6. 결론을 무너뜨릴 수 있는 현행 제도, 반대 연구, 예외 사례, 다른 정의를 탐색한다.
7. 기존 내부 결론과 충돌하면 기존 주장, 새 근거, 충돌 지점, 유지·수정 판단을 분리한다.

## 근거 강도

- 확인된 사실: 원문과 범위를 직접 확인함
- 종합 해석: 둘 이상의 근거를 연결한 분석
- 미검증 가설: 추가 자료가 필요한 가능성
- 실행 제안: 사실과 해석을 바탕으로 한 선택

검색에서 찾지 못한 것을 존재하지 않는다고 단정하지 않는다. 인용수, 검색순위, 요약문만으로 품질을 판정하지 않는다. 출처마다 확인 날짜와 직접 연결되는 주소 또는 파일명을 남긴다.

## 인도

조사 범위, 핵심 결론, 근거, 반증, 한계와 다음 확인 필요사항을 구분한다. 외부 문서에 사용할 문장은 확인된 근거 범위보다 강하게 쓰지 않는다.
