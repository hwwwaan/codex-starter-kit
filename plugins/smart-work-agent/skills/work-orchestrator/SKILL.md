# 복합업무 총괄

복잡한 요청을 작은 답변 여러 개로 흩뜨리지 말고 하나의 완결된 업무로 운영한다.

## 착수

1. 사용자의 실제 목적, 결과 사용자, 필요한 산출물, 기한, 제약을 요청과 작업공간에서 파악한다.
2. 관련 파일과 정본을 목록화하고, 결론에 영향을 주는 자료는 전문을 확인한다.
3. 정보가 조금 부족하면 합리적으로 가정하고 `가정`으로 표시한다. 방향·비용·개인정보·외부 행위가 달라지는 공백만 확인받는다.
4. 작업이 세 단계 이상이거나 여러 산출물이 연결되면 [총괄 플레이북](references/orchestration-playbook.md)을 읽고 적용한다.

## 운영 원칙

- 사실 확인과 사용자의 해석을 분리한다.
- 이전 산출물이 있으면 새 결과와 정합성을 검사한다.
- 지원 근거보다 결론을 무너뜨릴 반증과 예외를 먼저 찾는다.
- 사용자가 기술을 몰라도 가능한 파일 탐색, 변환, 계산, 검증은 직접 수행한다.
- 작업 범위 밖의 개선을 발견하면 본 작업을 먼저 끝낸 뒤 선택사항으로 짧게 보고한다.
- 외부 제출·발송·게시·결제·가입·권한 변경은 실행하지 않는다.

## 종료

완료 기준을 항목별로 대조하고 실제 파일과 검증 결과를 확인한다. 결과, 근거, 생성·수정 파일, 남은 불확실성을 한 번에 인도한다. 미완료 상태를 완료로 표현하지 않는다.
