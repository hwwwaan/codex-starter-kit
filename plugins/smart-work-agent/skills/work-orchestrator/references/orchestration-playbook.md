# 총괄 플레이북

## 작업 브리프

내부적으로 다음을 한 줄씩 확정한다.

- 목적: 이 일이 끝나면 무엇이 달라져야 하는가
- 사용자: 누가 결과를 읽거나 사용하는가
- 입력: 어떤 파일과 사실을 사용해야 하는가
- 출력: 필요한 파일 형식, 길이, 구성은 무엇인가
- 제약: 기한, 양식, 개인정보, 비용, 외부 행위 경계는 무엇인가
- 완료 기준: 무엇을 확인해야 완료인가

사용자에게는 방향 확인이 필요한 경우에만 브리프를 노출한다.

## 실행 흐름

1. 입력 목록과 누락 자료를 확인한다.
2. 기존 정본, 이전 결정, 최신 외부 사실을 구분한다.
3. 주장과 근거를 연결하고 충돌표를 만든다.
4. 가장 큰 불확실성과 실패 원인을 먼저 검토한다.
5. 산출물의 골격을 설계하고 실행한다.
6. 전체 산출물을 처음부터 끝까지 다시 읽는다.
7. 수치·인용·파일·형식·개인정보를 별도로 검사한다.
8. 결함을 수정하고 필요한 검증을 재실행한다.

## 교착 처리

도구나 파일 하나가 막혀도 바로 중단하지 않는다. 같은 목적을 달성할 수 있는 읽기 전용 대안, 다른 형식, 기존 원문, 수동 검증을 시도한다. 사용자 권한이나 외부기관의 답변이 반드시 필요한 경우에만 현재까지의 결과와 정확한 차단점을 보고한다.
