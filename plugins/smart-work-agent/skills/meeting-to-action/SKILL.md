# 회의를 실행계획으로 전환

회의 원문을 정리하되, 말하지 않은 합의나 책임을 만들어내지 않는다.

## 입력 확인

- 회의명, 날짜, 참석자와 자료 범위를 확인한다.
- 녹취가 여러 파일이면 시간순으로 배열하고 중복 구간을 표시한다.
- 발언자가 불명확하면 추정하지 않고 `발언자 미확인`으로 남긴다.

## 분류 기준

- 결정사항: 참석자가 합의하거나 확정한 내용만
- 실행과제: 수행할 행동이 명시된 내용
- 담당자: 원문에서 맡기로 한 사람만
- 기한: 실제 표현을 보존한다. `다음 회의 전`을 임의 날짜로 바꾸지 않는다.
- 미결 쟁점: 의견은 나왔지만 결론이 나지 않은 내용
- 확인 필요: 수치, 일정, 담당, 전제가 불명확한 내용

## 검증

각 결정과 과제가 원문의 어느 대목에서 나왔는지 추적 가능하게 한다. 서로 다른 발언이 충돌하면 하나로 합치지 말고 양쪽을 표시한다. 회의에서 논의되지 않은 배경지식은 별도 참고로만 추가한다.

## 기본 결과 구조

1. 회의 목적과 핵심 요약
2. 결정사항
3. 실행과제 표: 과제, 담당자, 기한, 완료 기준, 근거
4. 미결 쟁점과 확인 필요사항
5. 다음 회의 권장 의제

개인 평가, 감정 추정, 불필요한 민감정보는 제외한다.
