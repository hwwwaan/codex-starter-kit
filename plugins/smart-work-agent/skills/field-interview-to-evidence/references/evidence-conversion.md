# 인터뷰 답변 근거화 기준

## 입력을 먼저 고정한다

파일명, 인터뷰 일시, 참여자 역할, 기록 방식, 녹취 여부와 확인 범위를 적는다. 자료가 일부이거나 발언자가 불명확하면 그 한계를 먼저 표시한다. 직접 확인하지 않은 녹취 구간을 인용하지 않는다.

## 답변을 근거 단위로 나눈다

한 근거 단위에는 하나의 주장만 둔다. 각 단위에 다음을 붙인다.

- 근거 ID
- 참여자 역할과 답변 범위
- 직접 인용 또는 요약 구분
- 답변 유형: 구체적 사례, 반복 실무, 공식 원칙, 해석, 추정, 미확인
- 적용되는 기관·기간·대상·절차 단계
- 연결되는 기존 주장
- 반증·예외·충돌
- 추가 확인 필요사항

따옴표는 실제 발언과 대조한 문장에만 쓴다. 문장을 읽기 좋게 고쳤다면 직접 인용이 아니라 요약으로 남긴다.

## 강도를 판정한다

- `단일 출처`: 한 참여자의 경험이나 설명만 있음
- `교차 확인`: 다른 역할의 답변이나 문서가 같은 범위를 지지함
- `충돌`: 출처가 같은 절차를 다르게 설명함
- `범위 제한`: 특정 시점·사례·팀에만 적용됨
- `미확인`: 질문하지 못했거나 참여자가 알지 못함

인터뷰는 경험과 실제 흐름을 보여 주지만 빈도나 효과의 크기를 자동으로 증명하지 않는다. 여러 사람이 같은 말을 했다는 이유만으로 대표 표본이나 인과 근거가 되지는 않는다.

## 기존 주장과 대조한다

1. 인터뷰 전 주장을 그대로 적는다.
2. 지지하는 근거보다 먼저 반증·예외·충돌을 붙인다.
3. 문헌·정책상 원칙과 인터뷰에서 확인된 실제 이행을 나눈다.
4. 판단을 `유지 / 범위 축소 / 수정 / 보류 / 삭제` 중 하나로 기록한다.
5. 판단이 바뀌었다면 바뀐 문장과 이유를 함께 남긴다.

## 인도 전 확인

- 한 사람의 답변을 기관 전체 사실로 확대하지 않았는가
- 무응답과 미확인을 부재로 표현하지 않았는가
- 인용문이 실제 녹취와 일치하는가
- 해석과 추정에 참여자의 말처럼 따옴표를 붙이지 않았는가
- 충돌하는 답변을 임의로 평균내거나 하나로 합치지 않았는가
- 식별정보와 동의 범위 밖의 2차 사용을 제거했는가
