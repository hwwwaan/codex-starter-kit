# 산출물 기준

## 보고서·검토서

- 첫 부분에서 목적, 핵심 결론, 의사결정 필요사항을 분명히 한다.
- 배경, 현황, 분석, 대안, 권고, 실행계획이 논리적으로 이어지게 한다.
- 주장 가까이에 근거를 두고 사실과 제안을 구분한다.
- 표는 비교가 실제로 쉬워질 때만 사용한다.

## 제안서·계획서

- 문제의 크기보다 해결하려는 구체적 병목을 먼저 정의한다.
- 대상, 활동, 산출, 단기결과, 장기효과를 혼동하지 않는다.
- 일정, 담당, 비용, 위험, 성과지표를 실행 가능한 수준으로 쓴다.
- 기대효과를 근거 없이 확정 수치로 만들지 않는다.

## 발표자료

- 한 장에는 하나의 메시지를 둔다.
- 장표 제목만 읽어도 논리 흐름이 이어지게 한다.
- 본문을 보고서처럼 채우지 않고 발표자가 설명할 여백을 남긴다.
- 핵심 수치와 도표의 출처를 장표 안에서 추적 가능하게 한다.

## 안내문

- 독자가 해야 할 행동, 기한, 준비물, 문의처를 먼저 찾을 수 있게 한다.
- 내부 용어와 약어를 풀어 쓴다.
- 예외와 개인정보 처리 범위를 숨기지 않는다.

## 공통 최종검사

제목·목차·본문 구조, 수치와 단위, 인용과 출처, 용어 통일, 개인정보, 내부 흔적, 파일 열림과 페이지 배치를 확인한다.
