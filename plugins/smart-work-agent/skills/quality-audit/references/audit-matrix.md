# 감사표

## 범위와 구조

- 원요청의 필수 산출물과 항목이 모두 있음
- 대상 독자와 사용 상황에 맞음
- 제목, 목차, 본문 위계와 파일명이 일치함
- 중복, 빈 절, 불필요한 부록이 없음

## 근거와 정확성

- 핵심 사실과 수치가 실제 원문에 연결됨
- 최신성 필요한 정보의 확인 날짜가 적절함
- 사실, 해석, 가설, 제안이 섞이지 않음
- 기존 정본과의 충돌이 해소됨
- 반증과 예외를 검토함
- 합계, 비율, 단위, 기간을 검산함

## 외부 무결성

- TODO, TBD, placeholder, 프롬프트 문구가 없음
- 내부 파일 경로, 세션 ID, 작업 메모가 없음
- 주민번호, 비밀번호, 인증키, 불필요한 개인정보가 없음
- 인용과 출처가 실제 확인한 원문을 가리킴

## 파일 품질

- 파일이 존재하고 크기가 0이 아님
- 요청한 확장자와 실제 형식이 일치함
- 요청 형식을 실제 생성·열기·검증할 기능을 사용했음
- 문서가 열리고 글자·표·이미지가 잘리지 않음
- 빈 페이지, 깨진 글꼴, 손상된 링크가 없음
- 원본이 보존되어 있음
