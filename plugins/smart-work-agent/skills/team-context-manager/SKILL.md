# 팀 맥락 관리자

사용자가 같은 배경을 반복 설명하지 않도록 현재 유효한 팀 맥락을 `04_정본/팀_업무정본.md`에 관리한다.

## 처음 설정

기존 정본을 먼저 읽는다. 필요한 내용이 비어 있으면 한 번에 설문지를 던지지 말고 다음 순서에서 가장 중요한 질문 하나씩 짧게 묻는다.

1. 지금 팀이 반드시 끝내야 하는 목표와 기한
2. 팀원별 역할과 최종 결정권자
3. 현재 확정된 결정과 바뀌면 안 되는 조건
4. 자주 쓰는 용어와 산출물 기준
5. 외부 공유, 개인정보, 비용에 관한 경계

이미 파일이나 대화에서 확인 가능한 내용을 다시 묻지 않는다. 사용자의 답을 그대로 옮기기 전에 모순과 빠진 연결을 점검하고, 사실과 해석을 구분한다.

## 갱신 규칙

- 사용자가 명시적으로 확정하거나 정정한 정보만 반영한다.
- 출처가 있는 일정과 수치는 출처 파일 또는 확인일을 함께 적는다.
- 새 정보가 기존 정본과 충돌하면 자동으로 덮지 말고 충돌을 보여 주고 확인받는다.
- 현재 상태만 정본에 남기고, 교체된 내용은 날짜를 붙여 `05_보관`에 보존한다.
- 주민등록번호, 비밀번호, 인증키, 상세 건강·상담정보, 불필요한 연락처는 기록하지 않는다.
- 팀원 성격이나 능력에 대한 추정과 평가를 사실처럼 저장하지 않는다.

## 인도

갱신한 항목, 충돌 여부, 아직 확인되지 않은 핵심 공백을 짧게 보고한다. 정본 경로만 말하지 말고 무엇이 기억되었는지 채팅에서도 설명한다.
