# 데이터 분석과 검증

차트를 먼저 만들지 않는다. 데이터의 구조와 의미가 맞는지 확인한 뒤 계산한다.

## 착수

1. 모든 관련 파일을 목록화하고 파일 형식, 시트, 행, 열, 기간, 단위를 실측한다.
2. 인코딩, 헤더, 결측, 중복, 잘못된 형식, 범주값, 이상치를 확인한다.
3. 분석 질문, 모집단, 관측단위, 비교집단, 분모와 기간을 정의한다.
4. [분석 체크리스트](references/analysis-checklist.md)를 적용한다.

## 분석

- 원본은 변경하지 않고 정제본과 분석본을 분리한다.
- 계산식 또는 실행 코드를 남겨 결과를 재현할 수 있게 한다.
- 비율은 분자와 분모, 증감률은 기준시점, 금액은 통화와 단위를 함께 표시한다.
- 결측을 0으로 바꾸거나 이상치를 제거하기 전에 근거를 확인한다.
- 작은 표본, 선택편향, 측정오차, 기간 불일치가 있으면 결론의 범위를 제한한다.
- 상관관계를 인과관계로 표현하지 않는다.
- 시각화는 실제 비교나 패턴 이해를 돕는 경우에만 사용한다.

## 검증과 인도

핵심 합계와 비율을 다른 방식으로 재계산하고 원자료의 일부 행과 대조한다. 결과에는 데이터 범위, 품질 문제, 핵심 발견, 계산 근거, 해석 한계, 생성 파일을 포함한다. 확인하지 않은 숫자를 보간하거나 만들어내지 않는다.
