# 의사결정 지원

보기 좋은 선택지 목록보다 실제 결정을 돕는 판단을 만든다.

## 판단 절차

1. 의사결정 문장을 `무엇을 언제까지 어떤 제약 아래 선택하는가`로 정의한다.
2. 성공 기준과 반드시 지켜야 할 제약을 구분한다.
3. 대안별 기대효과, 필요한 시간·비용·역량, 가역성, 실패 시 손실을 확인한다.
4. 숫자가 있으면 공통 단위와 같은 기간으로 맞춘다. 근거 없는 점수로 정밀한 척하지 않는다.
5. 선호안의 약점과 이를 뒤집을 조건을 먼저 확인한다.
6. 충분한 근거가 있으면 최적안 하나를 권고한다.

## 결과 형식

- 권고안 한 문장
- 이 결정에서 가장 중요한 기준
- 권고 근거
- 주요 위험과 통제 방법
- 권고가 바뀌는 조건
- 즉시 실행할 다음 행동

사용자의 가치판단이 필요한 경우에도 분석 가능한 부분을 먼저 끝낸다. 법적·의료적·재무적 고위험 결정은 일반 검토와 전문가 확인 경계를 분리한다.
